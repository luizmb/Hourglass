# Third-Party Dependencies

Hourglass has **no runtime dependencies** beyond the Swift standard library and Foundation.

The only package dependency is a build-time documentation plugin:

| Package | Version | License | Purpose |
|---------|---------|---------|---------|
| [swift-docc-plugin](https://github.com/swiftlang/swift-docc-plugin) | ≥1.4.0 | Apache 2.0 | Documentation generation |

## Development Tools

Pinned in `Mintfile`:

| Tool | Version | License | Purpose |
|------|---------|---------|---------|
| [SwiftLint](https://github.com/realm/SwiftLint) | 0.63.2 | MIT | Code style enforcement |
| [Periphery](https://github.com/peripheryapp/periphery) | 3.7.4 | MIT | Dead code analysis |
| [SwiftFormat](https://github.com/nicklockwood/SwiftFormat) | 0.53.7 | MIT | Code formatting |
